# 中西文字体替换 · 案头工作台前端

设计与实现日期：2026-10-17。

## 视觉语言

- 三款扩展共用“案头”设计系统：暖纸底色、墨色正文、细线与衬线标题。本扩展主色为黛蓝 `#2e5a70`，深色模式使用 `#9fc3d4`。
- 界面字体通过 `@font-face` 与 `unicode-range` 拆成中西文两组本机别名。中文引号、破折号、省略号、间隔号与全角标点由中文字体排，西文、数字与代码符号由西文字体排；标题使用衬线别名，代码使用等宽别名。
- 颜色令牌集中在 `kit/kit.css`：纸 `#f4f0e7`、纸面 `#fffcf5`、墨 `#211f1b`、次级文字 `#4f4a43`；暗色使用暖黑纸面与米色文字。
- 页面标识、工具栏与扩展管理页沿用同一书籍印记；PNG 提供 16、32、48、128 像素。

## 交互与适配

- 顶部应用栏固定：保存状态、恢复默认与保存设置始终可达，`Ctrl+S` 或 `⌘S` 保存。
- 桌面为三栏：左侧章节目录、中间设置、右侧常驻试样。1024 像素以下隐藏目录，900 像素以下把试样移到设置之前并改为单列。
- 开关、分段选择、字符组、站点规则与折叠区由 `kit/` 统一提供，保留原生表单语义、焦点环与键盘操作。
- 支持明暗主题、强制颜色、减少动效、窄屏与 200% 缩放；未保存状态、保存中、成功与失败分别显示。

## 页面结构

1. 全局替换：总开关与说明。
2. 标点与字符：标点字体、可勾选的字符组、额外字符与首项名单；字符组用当前字体渲染真实字形。
3. 中文正文：黑体模式与名单，宋体与楷体并排设置，默认关闭。
4. 衬线组合：中文、西文两组字体与共用字符来源；与宋体替换互斥，切换时提示原因。
5. 网站设置：域名、站点行为、本站字体与中文模式。
6. 本机字体：按需读取字体内部名称，结果缓存在本机。

右侧试样常驻四组样例：无衬线正文、宋体、楷体与衬线组合。试样按当前草稿注册 `FontFace`，切换“查看原字形”可对照；底部显示已选字符与 Unicode 范围。工具栏弹窗处理当前站点替换行为、中文正文模式与全局开关。
