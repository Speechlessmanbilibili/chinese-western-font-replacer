- 新增手动字重映射，将多个本机字面按单值或区间组合为自定义家族，供标点、正文、前置西文、宋体、楷体及衬线组合使用。
- 字重区间支持 `~`、`～`、`—`、`-` 及 CSS 空格写法，离焦、按 Enter 确认或保存时统一显示为 `～`。
- 使用原生 `font-weight` 区间选择字面，保留闭区间、小数间隙及范围外字重的匹配行为。
- 正文、宋体与楷体支持通过 `local()` 调用完整字面及 PostScript 名，普通家族保留原生粗细选择。
- 本机字体名称索引区分家族与具体字面，缺少英文完整名称时优先使用 Windows 简中名称，并兼容旧名称缓存。
- 新增试样字重滑杆、字面加载提示与字重区间校验。
